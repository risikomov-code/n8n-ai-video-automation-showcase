# Public Showcase / Security Boundary

This repository is intentionally **not** a deployable copy of the production system.

## Public

- project purpose
- high-level architecture
- design principles
- technologies / capability areas
- non-sensitive case-study narrative

## Private

- credentials and tokens
- production URLs
- workflow exports
- full node logic
- prompts
- internal schemas
- asset IDs
- voice / avatar IDs
- exact provider configuration
- cost / routing rules
- production files and user data
- client or business-confidential information

No secret or production credential should ever be committed to this repository.
